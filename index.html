はじめに：Google Maps APIキー

このアプリは Google の Places API (New) と Maps JavaScript API を使います。 キーはこの端末のブラウザ内だけに保存され、外部には送信しません。 発行手順は右上「⚙ 設定 → 使い方」を参照。

気分・ジャンル

条件

現在地ボタンを押すか、地名を入力してください。

使い方 / APIキーの発行

実際の店舗・評価データは Google から取得します。無料枠がありますが、Googleアカウントと課金設定（クレカ登録）が必要です。

  1. Google Cloud Console でプロジェクトを作成
  2. 「APIとサービス」で Places API (New) と Maps JavaScript API を有効化
  3. 「認証情報」→ APIキーを作成
  4. （推奨）キーに HTTPリファラー制限 かアプリ制限をかける
  5. 下の欄にキーを貼り付けて保存

※ Google評価は食べログとは母数も基準も別物です。「4.4以上＝ハズレを弾く」目的の代理指標として使ってください。
※ このファイルはローカルで開いても動きますが、キーのリファラー制限を使う場合は簡易サーバー（例：python3 -m http.server）経由での表示を推奨します。
